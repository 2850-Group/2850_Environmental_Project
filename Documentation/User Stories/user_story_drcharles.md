### User Stories: Dr Charles

## User Story 1
**As a** researcher,
**I want to** filter and export outbreak data by region and time period,
**So that** I can see and analyse trends and produce reports.

**Acceptance Criteria:**
- Given I have filtered the data I need, When i click export, i can download it as a CSV file. 
- Given that I am viewing the data, when I apply the filters, The data updates to match my selections.
