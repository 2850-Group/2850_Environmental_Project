#### User Story 1
**As a** shop owner,
**I want to** be able to see if a crop is diseased,
**so that** I can dispose of them.

**Acceptance Criteria:**
- Given I think a crop is diseased, when I scan them, I can see if they are diseased or not
- Given that I have heard that a pest is spreading, when I look at the app, I can see what areas are being affected


#### User Story 2
**As a** Distribution Manager
**I want to** track affected areas,
**so that** I can direct resources there.

**Acceptance Criteria:**
- Given there is an outbreak, when I look at the map on the app, I can see affected areas and nearby farms
- Given that I want to prevent contamination, I can use the app, so that I can mark farms as contaminated
