#### User Story 1
**As a** shop owner,
**I want to** be able to see if a crop is diseased,
**so that** I can dispose of them.

**Acceptance Criteria:**
- Given I think a crop is diseased, when I scan them, I can see if they are diseased or not
- Given that I have heard that a pest is spreading, when I look at the app, I can see what areas are being affected


#### User Story 2
**As a** Distribution Manager
**I want to** track affected areas,
**so that** I can direct resources there.

**Acceptance Criteria:**
- Given there is an outbreak, when I look at the map on the app, I can see affected areas and nearby farms
- Given that I want to prevent contamination, I can use the app, so that I can mark farms as contaminated


#### User Story 3
**As a** farmer,
**I want to** scan a crop and get a plain language result,
**so that** i know whether it's affected and what to do next.

**Acceptance Criteria:**
- Given i have a taken a photo of a crop, when the scan is complete, I can see a clear result that doesnt use technical, unclear, or hard to understand terminology. 
- Given that the crop is identifies as affected, when I view the result, I can see a simple recommended next step
    - eg: monitor, remove, isolate, etc. 

#### User Story 4
**As a** researcher,
**I want to** filter and export outbreak data by region and time period,
**so that** I can see and analyse trends and produce reports.

**Acceptance Criteria:**
- Given I have filtered the data I need, When i click export, i can download it as a CSV file. 
- Given that I am viewing the data, when I apply the filters, The data updates to match my selections.
