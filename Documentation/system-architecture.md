# System Architecture


## Overview

A single integrated web application consisting of:

1. **Community Dashboard** — public-facing, displays current conditions, status, alerts, and basic trends
2. **Data Management & Alerts** — handles data ingestion, validation, storage, alert rule evaluation, and alert logging
3. **Analysis & Reporting Portal** *(extension — decide if implementing)* — researcher/decision-maker view with filters, trend comparisons, and export
