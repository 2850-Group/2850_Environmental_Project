### User Stories: John

## User Story 1
**As a** shop owner,
**I want to** be able to see if a crop is diseased,
**So that** I can dispose of them.

**Acceptance Criteria:**
- Given I think a crop is diseased, when I scan them, I can see if they are diseased or not
- Given that I have heard that a pest is spreading, when I look at the app, I can see what areas are being affected

## User Story 2
**As a** shop owner,
**I want to** easily use the app,
**So that** I do not find it too hard to check my crops.

**Acceptance Criteria:**
- Given that I want to check if a crop is diseased, when I go to use the app, I can easily navigate to the relevant section
- Given that I have never used the app before, when I use it for the first time, I want to be able to easily tell what everything does

## User Story 3
**As a** shop owner,
**I want to** not buy crops from a diseased area,
**So that** I do not sell bad crops to customers.

**Acceptance Criteria:**
- Given that there is a diseased area, when I look at the app, I want to be able to see areas with diseased crops
- Given that there is an area that is fine, when I look for areas on the app, I want to see that certain areas are fine
