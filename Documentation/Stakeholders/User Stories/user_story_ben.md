### User Stories: Ben

## User Story 1
**As a** farming community coordinator,
**I want to** view all disease reports in one central dashboard,
**So that** I can quickly identify patterns and warn unaffected members before the outbreak spreads.

**Acceptance Criteria:**
- Given there are disease reports, when I view the dashboard, I can see all reports and their locations
- Given multiple reports appear in one area, I can identify patterns and alert nearby farms

## User Story 2

**As a** farming community coordinator,
**I want to** compare the severity of reported outbreaks across different farms,
**so that** I can prioritise urgent cases and give targeted advice instead of sending generic warnings to everyone.

**Acceptance Criteria:**
- Given multiple outbreak reports, when I use the comparison feature, I can see the severity of each case
- Given some outbreaks are severe, I can prioritise those farms and send targeted advice

## User Story 3

**As a** farming community coordinator,
**I want to** view the trend of past outbreaks in my local area by season,
**so that** anticipate recurring threats.

**Acceptance Criteria:**
- Given historical data exists, when I view the trends section, I can see outbreaks by season
- Given a seasonal pattern appears, I can warn farms in advance.
