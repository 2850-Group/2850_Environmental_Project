#### User Stories: Stephanie

## User Story 1 

**As a** Distribution Manager
**I want to** track affected areas,
**so that** I can direct resources there.

**Acceptance Criteria:**
- Given there is an outbreak, when I look at the map on the app, I can see affected areas and nearby farms
- Given that I want to prevent contamination, I can use the app, so that I can mark farms as contaminated

## User Story 2

**As a** Distribution Manager
**I want to** quickly scan plants,
**so that** I can identify breakouts.

**Acceptance Criteria:**
- Given there is a diseased plant, I can use the app, to scan a plant and find the disease
- Given there is a diseased farm, I can use the app, to mark the farm as diseased

## User Story 3

**As a** Distribution Manager
**I want to** see all locations on a map,
**so that** I can manage outbreaks.

**Acceptance Criteria:**
- Given there is an outbreak at at farm, I can look at the map, to see exactly where the outbreak is
- Given there is a outbreak, I can look at a map, to see nearby farms and alert them
