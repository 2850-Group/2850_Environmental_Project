### User Stories: Dr Charles

## User Story 1
**As a** researcher,
**I want to** filter data by region, timings and type,
**So that** I can see and analyse trends and produce reports.

**Acceptance Criteria:**
- Given that I am viewing the data, when I apply the filters, The data updates to match my selections. 

## User Story 2
**As a** researcher,
**I want to** export the data provided after I have filtered it,
**So that** I can use other tools to provide data analysis and store it locally to aid my research.

**Acceptance Criteria:**
- After data has been displayed, a button can be clicked to export the data
- When the button is clicked, it will download a csv file with data displayed that can be stored locally
