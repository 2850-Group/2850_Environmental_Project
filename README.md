# 2850_Environmental_Project
> COMP2850 - University of Leeds - COIL Group 1

A mobile application that displays live crop sensor data to help farmers and agricultural workers detect pest and disease risks early, and monitor environmental conditions in the field.

---

### Prerequisites

```
pip install kivy kivymd bcrypt opencv-python python-dateutil tensorflow pytest
```

### Setup

```
# 1. Clone the repo
git clone https://github.com/2850-Group/2850_Environmental_Project.git
cd 2850_Environmental_Project

# 2. Create and activate a virtual environment
python3 -m venv venv
source venv/bin/activate        # Mac/Linux
venv\Scripts\activate           # Windows

# 3. Install dependencies
pip install kivy kivymd bcrypt opencv-python python-dateutil tensorflow pytest

# 4. Run the app
python Dashboard.py
```
